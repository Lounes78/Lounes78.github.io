# Lounes Benali — Portfolio

The public site is available at [b-lounes.github.io](https://b-lounes.github.io/).

This branch is a conservative refresh of the original portfolio. It keeps the
original palette, typography, particles, diagonal transitions, portrait, and
overlapping project layout while updating the content from the July 2026 CV.

## Local preview

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open [http://127.0.0.1:4173/](http://127.0.0.1:4173/).

## Refresh scope

- Current experience and education, including the ongoing IFM/MBZUAI internship
- Curated projects and canonical `B-Lounes` links
- Downloadable current CV and updated social metadata
- Responsive project cards and mobile navigation
- Semantic headings, keyboard support, reduced-motion handling, and lazy media
- Removal of the old loader, browser warning, and fragile generator dependencies
